# Agent Guidelines

This document provides optional guidance for working with this codebase.

## Best Practices

### When Exploring Code
- Use search tools to find relevant code
- Read related files to understand context
- Check for dependencies and relationships

### When Debugging
- Identify the error or symptom
- Trace through related functions
- Check recent changes if it's a regression

### When Refactoring
- Consider the impact of changes on dependent code
- Use semantic rename tools when available
- Test thoroughly after refactoring
- Verify only expected files were changed

### Before Committing
- Review all changes
- Run tests if available
- Check that changes match the intended scope

## General Guidelines

- Read code before making claims about it
- Understand the context before making changes
- Test changes when possible
- Document significant modifications
- Consider backward compatibility
- Follow existing code patterns and conventions
